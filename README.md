# Catálogo Oficial Web KöDE 2026

Catálogo interactivo de perfumes KöDE con experiencia optimizada para móviles, selector de concentración, cálculo dinámico de promociones y generación de pedidos directos a WhatsApp.

## Características
- Catálogo interactivo de perfumes con búsqueda y filtros por diseñador y género.
- Ficha técnica completa de fragancias con pirámides olfativas y acordes principales.
- Selector de formulación: Clásica (30%) y Extra Shot (45%).
- Sistema de descuentos dinámicos en tiempo real (ofertas por 2da unidad).
- Generación automática del mensaje estructurado para vendedoras en WhatsApp.
- Despliegue estático de alto rendimiento listo para Vercel o cualquier hosting web.
